# Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my **skills, projects, professional experience, services, and achievements**. The portfolio provides an interactive and user-friendly interface with smooth animations and responsive design for different screen sizes.

### 🚀 Features

* Responsive and modern UI design
* Personal introduction and About Me section
* Projects/Work showcase
* Services section
* Experience and internship details
* Technical skills section
* Testimonials section
* Contact form
* Social media and GitHub links
* Smooth scrolling and interactive animations
* Swiper.js slider for project/testimonial sections
* Typed.js and ScrollReveal animations

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Swiper.js
* Typed.js
* ScrollReveal.js
* EmailJS
* Remix Icons
* Figma

### 📂 Projects Featured

* Footwear Website
* Student Performance Prediction System
* Personal Portfolio Website

### 🎯 Purpose

This portfolio was developed to create a professional online presence and provide recruiters and clients with an overview of my **technical skills, projects, experience, and capabilities**.
